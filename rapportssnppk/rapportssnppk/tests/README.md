# Tests de recette recommandés
- National : impossible de lire un rapport SUBMITTED via l'API.
- Régional : impossible de modifier un rapport.
- Superviseur : impossible de modifier un Bowl verrouillé.
- National : modification d'un Bowl verrouillé exige un motif et génère un audit.
- Validé : modification réservée au Super Admin en procédure exceptionnelle.
- Offline : création GPS sans réseau ajoutée à la file IndexedDB.
- Reconnexion : file envoyée automatiquement.
